# Recommended IDE extensions (proto)

Install in Cursor or VS Code for uncommitted + PR review:

| Extension | ID | Why |
|-----------|-----|-----|
| Git Tree Compare | `letmaik.git-tree-compare` | Working tree vs branch — file list → diff → open file |
| GitHub Pull Requests | `github.vscode-pull-request-github` | PR comments/merge after checkout |
| Claude Diff & Edit | `dfarkash.claude-edits-scm` | Spike: Claude session changed-files sidebar |

```bash
cursor --install-extension letmaik.git-tree-compare
cursor --install-extension github.vscode-pull-request-github
cursor --install-extension dfarkash.claude-edits-scm
# or: code --install-extension …
```
