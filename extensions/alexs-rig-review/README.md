# Alex's Rig Review

One **Viewed** list for **this session** and the **current pull request**. Same checkbox as GitHub PR Files. Not wired into Microsoft’s GitHub Pull Requests extension.

1. Open **Source Control → Review**.
2. Toolbar: **session** (since session open) or **pull request** (vs PR base, including local edits). If this branch has a PR, it starts on PR.
3. Click a file → native diff. Check the box → viewed. Content change unchecks.

Comments / approve / merge on GitHub still need the browser or the optional GitHub Pull Requests extension. This view is the file list + Viewed + diff.

Install: `./scripts/install_review_extension.sh` then Reload Window.
